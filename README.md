### 🎓 [NMIET Student Support: Agentic RAG Chatbot](https://github.com/shantanuvhanmore/<repo-name>)

*Fees. Attendance. Documents. Ask in plain English instead of "come back tomorrow."*

[![Live Demo](https://img.shields.io/badge/▶%20LIVE%20DEMO-nmiet--student--support-6366f1?style=for-the-badge)](https://nmiet-student-support.algokami.tech)
[![Paper](https://img.shields.io/badge/📄%20PAPER-ICITSC%202025-0ea5e9?style=for-the-badge)](https://www.scitepress.org/Link.aspx?doi=10.5220/0014708700004852)

| 🎯 Faithfulness (RAGAS) | 😊 Student satisfaction | 👥 Launch week | 📨 Queries |
|:---:|:---:|:---:|:---:|
| **0.48 → 0.86** | **80–85%** (56-student study) | **35 users** | **182** |

</div>

**Stack:** Node.js · React · MongoDB Atlas Vector Search · OpenAI / Gemini · Tavily · Google OAuth + JWT
**What's inside:** LLM query decomposition, section-aware retrieval, web-search augmentation, admin analytics, rate limiting.
*Demo runs on a 2025 data snapshot; the college has since changed its ERP. I wrote up what the launch taught me in the repo README.*
